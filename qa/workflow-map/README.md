# Video Agent workflow preview

The current standalone workflow is `index.html`. A packaged copy is wired into the portfolio StudioDeck architecture face at `public/media/creator-studio/workflow/`. The front face uses the supplied recording `public/media/creator-studio/demo.mp4`.

Run from the repository root:

```powershell
python -m http.server 5185 --bind 127.0.0.1 --directory qa/workflow-map
```

Open http://127.0.0.1:5185/ . The alternative input treatments are in `input-comparison.html`.

The animation is illustrative, silent, and does not invoke production services. The current loop lasts 68 seconds; controls support pause, replay, seeking, and reduced motion.

Edit `progressive.py` to change the workflow animation and regenerate with `python qa/workflow-map/progressive.py`. It takes the setup prefix from `journey-continuous.js`; that file is not a standalone current player. `details.js` and `details.css` provide the icon and visual treatment. The heading and introductory quote are static SVG in `index.html`.

`icons.json` contains Phosphor icon artwork generated by `polish.mjs`; platform logo provenance is recorded in `logos/sources.md`. Screenshots, downloaded reference videos, and temporary verification outputs are intentionally excluded from Git.
